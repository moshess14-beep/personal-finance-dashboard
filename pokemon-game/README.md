# ציד פוקימונים 🐾

משחק פשוט לילדים: מתחילים עם פיקאצ׳ו כבן לוויה, מסתובבים בעולם קטן עם עשב, עצים ואבנים, ומחפשים פוקימונים פראיים שמסתתרים בעשב הגבוה. ההתקרבות פותחת אפשרות לזרוק כדור פוקימון — תפיסה מוצלחת דורשת תזמון טוב במיני-משחק הטבעת, ולא כל פוקימון נתפס בניסיון הראשון.

## איך משחקים

פתחו את `index.html` בדפדפן (לא נדרש שרת או התקנה). שליטה בחצים/WASD במחשב, או בכפתורי החצים על המסך בנייד. כשמופיע הכפתור האדום "זרוק כדור פוקימון" — לחצו עליו ונסו לתפוס בזמן הנכון.

ההתקדמות (אוסף הפוקימונים) נשמרת אוטומטית בדפדפן (localStorage).

לא נעשה שימוש בקבצי תמונה או נכסים חיצוניים — כל הגרפיקה מצוירת על Canvas עם אימוג׳י, למטרות שעשוע אישי ופרטי בלבד.
